# Yambda / Signal v2

Интерактивная сонфикация датасета
[Yambda](https://huggingface.co/datasets/yandex/yambda): браузер превращает
историю взаимодействий с музыкой в ритм, тембр, пространство и редкие
смысловые акценты. Это не проигрыватель треков из датасета — весь звук
синтезируется локально через Web Audio API.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173` в Chrome или Safari/WebKit и нажмите
**«Запустить звук»**. Первый жест нужен из-за браузерной политики autoplay.
Лучше слушать в наушниках.

Приложение не требует сборки, npm-пакетов, внешних аудиофайлов или сетевых
запросов после загрузки страницы.

## Два уровня интерфейса

- **Signal** — художественный режим: профиль поведения, временная линза,
  единый ползунок Structure и скрытый по умолчанию score.
- **Lab** — Advanced-страница: источник, нормализация, разрешение событий,
  параметры времени, слои, матрица, Event Inspector, синтез, эффекты,
  тональность, guide-click и локальные пресеты.

Переключение Signal / Lab происходит без перезагрузки и без остановки звука.

## Structure: упростить или усложнить всю историю

Structure меняет не громкость и не количество случайных нот, а разрешение
одной и той же сонфикации:

| Диапазон | Стадия | Что слышно |
| --- | --- | --- |
| 0–24 | Essence | 4 крупных жеста по 4 исходных события; Listen + Feedback |
| 25–49 | Contour | 8 жестов по 2 события; добавляется контур длины трека |
| 50–74 | Signal | все 16 событий и четыре смысловых слоя |
| 75–100 | Swarm | 16 событий + детерминированные replay/transition micro-events |

При агрегации `played_ratio_pct` и `track_length_seconds` берутся по медиане,
`is_organic` становится долей organic внутри группы, а временные интервалы
суммируются. Лайки, дизлайки и ранние skip не усредняются: они сохраняются как
landmarks на любом уровне сложности. Компенсация усиления не даёт сложным
сценам автоматически звучать громче простых.

## Время без обязательной сетки

- **Flow** — режим по умолчанию. Разрывы из `timestamp` логарифмически
  сжимаются в слушаемый диапазон, а в конце цикла остаётся «вдох». Здесь
  Listen становится дыханием фильтра, а не бочкой. BPM и swing не управляют
  историей.
- **Pulse** — аналитическая 4/4-сетка для сравнения рисунков. BPM и swing
  работают, но события не создаются искусственно через номер шага.
- **Elastic** — исходное время мягко притягивается к сетке параметром Grid
  Gravity; при 0% это Flow, при 100% — почти Pulse.

Слышимый guide-click выключен по умолчанию, не является частью данных и
доступен только в Lab. Поэтому основной Flow можно слушать совсем без
метронома и без видимой сетки; матрица остаётся аналитическим инструментом.

## Как поля Yambda становятся звуком

- `played_ratio_pct` → сила/огибающая Listen; в Pulse это короткий импульс, в
  Flow — дыхание громкости и фильтра;
- `track_length_seconds` → ступень выбранной гаммы и басовый голос;
- `is_organic` → equal-power crossfade тёплого и цифрового тембра;
- `like` → светлый гармонический отклик;
- `dislike` → низкий шумовой разлом;
- ранний skip (`played_ratio_pct < 50`) → короткий шумовой маркер;
- `played_ratio_pct > 100` → replay-эхо на стадии Swarm;
- `timestamp` → расстояние между событиями в Flow/Elastic.

В Event Inspector можно выбрать ячейку и увидеть путь `raw value → normalized
value → sound mapping`, исходный диапазон событий и salience. Клик по ячейке
включает или исключает конкретный смысловой голос, не меняя локальные данные.

## Что взято из датасета

Yambda-5B содержит 4,79 млрд взаимодействий 1 млн пользователей с 9,39 млн
треков. В репозитории датасета есть listen/like/dislike/unlike/undislike,
organic/recommendation-маркеры и время, квантованное по 5 секунд.

`yambda-data.js` содержит три небольших демонстрационных профиля по официальной
схеме, а не сырые истории конкретных пользователей. Редкие реакции намеренно
сделаны различимыми в коротком 16-событийном фрагменте. Никакие персональные
данные или аудиозаписи в приложение не включены.

Код приложения распространяется по GPL-3.0 из этого репозитория. Карточка
Yambda указывает Apache-2.0 для датасета; сам датасет в репозиторий не
копируется.

## Аудиодвижок

Архитектура разделена на три этапа:

```text
buildScene(profile, structure)
→ buildTimeline(scene, timeMode)
→ scheduleGesture(gesture, absoluteAudioTime)
```

Планировщик работает по часам `AudioContext` с look-ahead, поэтому отрисовка не
управляет музыкальным временем. Все осцилляторы, шум, delay, convolution
reverb, compressor и analyser создаются в браузере. Поддерживаются стандартный
`AudioContext` и WebKit fallback `webkitAudioContext`.

## Файлы

- `index.html` — Signal/Lab и доступная разметка;
- `styles.css` — адаптивная визуальная система;
- `yambda-data.js` — компактные Yambda-профили и метаданные;
- `app.js` — агрегация, timeline, Web Audio, инспектор и управление;
- `tests/smoke.mjs` — zero-dependency проверка интерфейсного и data-контракта.
